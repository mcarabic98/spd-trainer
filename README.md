# SPD Trainer

**Тренер и набор инструментов тестирования для [Shattered Pixel Dungeon](https://shatteredpixel.com)**
Работает поверх **официальной сборки игры**: банка игры не изменяется, не пересобирается и не заменяется — трейнер подгружается отдельным jar-оверлеем при запуске.

[English version](README.en.md)

---

## Возможности

Меню открывается в игре: **ESC → кнопка «Тренер»**. Одно большое окно, вкладки внизу.

| Вкладка | Что умеет |
|---|---|
| **Читы** | Режим бога (перехват урона), полное здоровье, +1000 золота, +1 уровень, +1 сила, открытие карты, снятие голода, перезарядка жезлов |
| **Предметы** | 18 категорий: оружие, метательное, броня, жезлы, кольца, артефакты, зелья, свитки, руны, семена, еда, безделушки, экзотические зелья/свитки, бомбы, ключи, квестовые, прочее. Редактор предмета: количество, уровень улучшения (±2 млрд), заряды жезлов (без кэпа), тумблеры проклятий/известности, зачарования и проклятия оружия, глифы и проклятия брони |
| **Герой** | HP, максимум HP, уровень, сила, золото — точными значениями до 2 млрд; точные стадии голода (сыт/голоден/голодает); сброс талантов |
| **Баффы** | ~80 статусов с иконками: положительные, отрицательные, механики классов; спец-режимы (Barrier — размер щита, Healing — пул лечения); секция «на ближайшего моба» (дебаффы и метки снайпера — врагу); снять все баффы |
| **Мобы** | Полный бестиарий игры (по внутренним спискам `Bestiary`): 5 зон, боссы (все кулаки Йога, личинка), универсальные, редкие, квестовые (включая хранилище), NPC, союзники (зеркала, стражи жезлов и др.). Спавн с выбранным количеством, режим союзника, очистка этажа |
| **Данж** | Телепорт на этаж 1–25, **телепорт в произвольную точку** (выбор клетки), к входу/выходу этажа, просмотр и установка seed генерации |
| **Инфо** | **Инспектор живого состояния**: панель обновляется 3 раза/с — этаж/ветка/тип уровня, координаты героя, HP/HT/уровень/сила/опыт, золото, seed, счётчик ходов, статистика, состав мобов по фракциям, кучки и ловушки, активные баффы с остатком ходов. Кнопка **«Осмотреть клетку»** — прицел по клетке и отладочная сводка: тайл, ловушка, предметы, моб с HP и баффами |

Числовые поля — до 32-битных значений. Осознанные ограничения: уровень героя 1–30 (массив порогов талантов в игре), этажи 1–25, количество мобов за раз ≤ 100 (производительность).

Все действия пишутся в лог (`[SPD-TRAINER] ...`), включая стектрейсы при ошибках.

## Быстрый старт

1. Установите **JDK 17+** (проверено на 25; нужен `java`/`javac` в PATH).
2. Скачайте официальную **Shattered Pixel Dungeon (Java)** с [shatteredpixel.com](https://shatteredpixel.com) или из [releases игры](https://github.com/00-Evan/shattered-pixel-dungeon/releases) и положите `ShatteredPD-vX.X.X-Java.jar` в корень репозитория.
3. Запустите **`SPD-Trainer.bat`** — игра стартует с трейнером (готовый `dist/spd-trainer.jar` уже в комплекте, консоль свернётся, вывод пишется в `trainer.log`).
4. В игре: **ESC → «Тренер»**.

## Сборка из исходников

Требуется только JDK: пересобирается маленький оверлей (~90 КБ), **игра не пересобирается** — `javac` компилирует наш код прямо против официальной банки.

### Windows

```bat
build-trainer.bat
```

Результат: `dist\spd-trainer.jar`. Если `jar.exe` не в PATH, скрипт сам найдёт его в стандартном каталоге JDK.

### Linux / macOS / вручную

```bash
mkdir -p build/classes dist
javac --release 11 -encoding UTF-8 \
  -cp ShatteredPD-v4.0.2-Java.jar -d build/classes \
  src/main/java/com/shatteredpixel/shatteredpixeldungeon/trainer/*.java \
  src/main/java/com/shatteredpixel/shatteredpixeldungeon/actors/Char.java \
  src/main/java/com/shatteredpixel/shatteredpixeldungeon/windows/WndGame.java
jar --create --file dist/spd-trainer.jar -C build/classes .
```

Запуск вручную (то, что делает `spd-trainer-run.cmd`):

```bash
java -DSpecification-Title="Shattered Pixel Dungeon" -DSpecification-Version=4.0.2 \
  -DImplementation-Title=com.shatteredpixel.shatteredpixeldungeon -DImplementation-Version=922 \
  --enable-native-access=ALL-UNNAMED \
  -cp "dist/spd-trainer.jar;ShatteredPD-v4.0.2-Java.jar" \
  com.shatteredpixel.shatteredpixeldungeon.desktop.DesktopLauncher
```

(на Linux/macOS разделиитель classpath — `:` вместо `;`).

`-D`-свойства обязательны: они дублируют манифест официальной банки, чтобы игра использовала **те же сохранения и настройки**, что и при обычном запуске.

### Проверка сборки

`tools/TestLoad.java` — линк-тест: проверяет, что все классы оверлея линкуются с официальной банкой.

```bash
javac -cp ShatteredPD-v4.0.2-Java.jar -d build tools/TestLoad.java
java  -cp "dist/spd-trainer.jar;ShatteredPD-v4.0.2-Java.jar;build" TestLoad
```

Ожидаемый вывод — `ALL CLASSES LINKED` и список классов, загруженных из оверлея.

## Как это работает

Игра — Java-приложение (libGDX поверх собственной обвязки noosa). Трейнер использует **класс-шейдинг**: в classpath наша `dist/spd-trainer.jar` стоит **первой**, официальная банка — второй. Пакеты официальной банки не запечатаны (`Sealed` в манифесте нет), поэтому одноимённые классы загружаются из оверлея, а всё остальное — из нетронутой игры.

Состав оверлея:

- **Пакет `trainer`** (только наш код, `src/`): `Trainer` — вся логика; `WndTrainer` — главное окно с вкладками; `WndTrainerItem` — редактор предмета; `TrainerSpinner` — спиннер с диалогом ввода (Set/Cancel); `WndInspectCell` — окно осмотра клетки.
- **Два пропатченных класса игры** (полные копии исходников v4.0.2 с минимальными вставками; справочный diff — в `patches/game-over-v4.0.2.patch`):
  - `Char.java` — 5 строк: god mode в `damage()`;
  - `WndGame.java` — кнопка «Тренер» в игровом меню.
- Компиляция идёт **против официальной банки** — полный клон исходников игры для сборки не нужен. Полные исходники v4.0.2 лежат у [апстрима](https://github.com/00-Evan/shattered-pixel-dungeon).

Ключевые нюансы движка, которые пришлось учесть (описано, чтобы не наступить снова):

- окна трейнера **игнорируют наследуемый офсет** (`Window.offset`) — иначе контент прокрутки «уезжает» на пол-окна;
- панель прокрутки **самолечится каждый кадр** (`RefreshableScrollPane`) — что-то в игре двигает камеру контента;
- панель прокрутки создаётся **до** наполнения кнопками, иначе её контроллер глотает клики (стек событий: кто позже зарегистрирован — тот выше);
- телепорт по этажам идёт через `InterlevelScene.Mode.RETURN` (путь через `DESCEND` требует объект перехода и падает с NPE);
- метательные «сеты» игра обрезает до `defaultQuantity()` при слиянии стеков — трейнер заранее нарезает количество на отдельные наборы.

## Разработка

Исходники игры для навигации по коду (не обязательны для сборки) можно положить рядом:

```bash
git clone --branch v4.0.2 --depth 1 https://github.com/00-Evan/shattered-pixel-dungeon.git game
```

Каталог `game/` в `.gitignore` — в репозиторий не попадает.

Где что искать:

| Задача | Файл |
|---|---|
| Новое действие (чит) | `src/.../trainer/Trainer.java` — метод + лог; вызвать из вкладки |
| Новая вкладка | `src/.../trainer/WndTrainer.java`: константа `TAB_*`, имя в `TAB_NAMES`, билдер `buildXxxTab`, ветка в `switch` |
| Новая категория предметов | `WndTrainer.java`: `CAT_NAMES` + пустой элемент `CATEGORIES` + список `EXTRAS` |
| Новые баффы/мобы в списки | `WndTrainer.java`: массивы `BUFF_SECTIONS` / `MOB_SECTIONS` |
| Зачарования/глифы | `WndTrainerItem.java`: массивы `WEAPON_ENCHANTS`, `ARMOR_GLYPHS` и т.д. |
| Список компилируемых файлов | `build-trainer.bat` (это и есть реестр изменений игры) |

Изменённые классы игры всегда добавляются в список `build-trainer.bat` — забыли добавить = класс не попадёт в оверлей.

## Устранение неполадок

| Симптом | Причина и решение |
|---|---|
| Bat запускается и исчезает, игра не стартует | `java` не в PATH. Установи JDK и перезапусти терминал, либо пропиши полный путь в `spd-trainer-run.cmd` |
| `PACKAGING FAILED` при сборке | Игра запущена и держит `dist/spd-trainer.jar`. Закрой игру и пересобери |
| Меню не открывается | Убедись, что игра запущена через `SPD-Trainer.bat`, а не сама по себе |
| Что-то сломалось в игре | Посмотрите в `trainer.log` — там логи трейнера и стектрейсы |
| Числа больше 2 147 483 647 | Это потолок int (32 бита) — введите значение клавиатурой, стрелки спиннера не дотянутся |

## Обновление на новые версии игры

Оверлей привязан к v4.0.2. Для новой версии: скачайте новую официальную банку, склонируйте исходники новой версии (см. «Разработка»), сверьте две наши копии в `src/` (`Char.java`, `WndGame.java`) с новыми исходниками и перенесите вставки (`patches/game-over-v4.0.2.patch` показывает объём правок — он маленький); при изменениях API поправь вызовы в пакете `trainer`.

## Структура репозитория

```
spd-trainer/
├── SPD-Trainer.bat          # запуск игры с трейнером (свёрнутая консоль → trainer.log)
├── spd-trainer-run.cmd      # однострочный запуск java (вызывается батником)
├── build-trainer.bat        # сборка dist/spd-trainer.jar
├── src/main/java/.../       # исходники трейнера:
│   ├── trainer/             #   наш пакет (Trainer, окна, спиннер)
│   ├── actors/Char.java     #   пропатченная копия (god mode)
│   └── windows/WndGame.java #   пропатченная копия (кнопка «Тренер»)
├── dist/spd-trainer.jar     # собранный оверлей (в git не хранится)
├── tools/TestLoad.java      # линк-тест оверлея против официальной банки
├── patches/                 # справочный diff изменённых классов игры
├── game/                    # опциональный клон исходников игры (в git не хранится)
└── README.md
```
